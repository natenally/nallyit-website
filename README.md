# Nally Consulting website

Static website for Azure Static Web Apps.

## Publish
Upload all files in this folder to the root of the `main` branch of `natenally/nallyit-website`.

## Before enabling integrations
- Replace `G-XXXXXXXXXX` in `index.html` with the Google Analytics 4 measurement ID and enable the scripts.
- Replace `YOUR_CLARITY_ID` in `index.html` with the Microsoft Clarity project ID and enable the script.
- Replace the Bookings placeholder with the published Microsoft Bookings link or embed.
- Replace the email-preparation form with Microsoft Forms/Power Automate when the form URL and workflow are ready.
- Review and expand `privacy.html` and `terms.html` before enabling analytics or collecting data through third-party forms.
